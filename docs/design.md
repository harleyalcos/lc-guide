# LC Guide interface direction

Audience: Laguna College students. The home page has one job: make it easy to ask a handbook question or start reading.

The supplied image sets the direction: navy ink `#10234D`, cobalt `#3F65D8`, pale sky `#EEF3FD`, white `#FFFFFF`, and muted blue `#7483A0`. The reader uses white paper, black Arial-style text, and an amber citation highlight. DM Sans carries the interface; the printed handbook layout is rebuilt with native text and stable page coordinates, scaled uniformly during zoom.

The layout keeps the brand and welcome above three question suggestions, with a bottom question composer and browse action. A conversation uses the same surface. The book reader is an overlay that returns to the question without losing it. The answer’s source link fades directly into the cited page, followed by a passage highlight. Reader entry has no rotating cover or 3D transform. Page navigation uses a 620 ms hinged paper leaf over a stationary page, with direction-aware motion and fold shading. Only the paper rotates; the toolbar, footer, and screen stay stationary. Navigation is locked until a turn finishes. Reduced motion uses instant page changes. The two closing pages are named Awit ng Laguna College and The Laguna College Hymn throughout the reader.

The supplied original college seal is used on the home screen. The launcher icon is a custom book mark. The reference image's campus background is omitted because a separate authentic source asset was not supplied. The forty original handbook photographs are the visual authority for the reader, and remain unchanged as development references. They are not displayed as reader backgrounds. Each of the forty pages has a clean native text layout; page 3 follows the supplied digitized reference.
